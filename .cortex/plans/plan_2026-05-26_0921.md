## Implementation Plan: Improvements to SR OneStream Dim Builder

### Context

After thorough exploration, I found that:
- The 5 missing validation rules (`ROOT_MEMBER_MISSING`, `SELF_REFERENCING_RELATIONSHIP`, `MEMBER_NAME_LEADING_TRAILING_WHITESPACE`, `DUPLICATE_MEMBER_CASE_INSENSITIVE`, `MEMBER_NAME_STARTS_WITH_DIGIT`) are **already implemented** in `validationEngine.ts`
- The diff route 404 is a documentation issue — the route is `POST /:projectId/diff` (singular), not `/diffs`
- The member PATCH 500 is a body format issue — the endpoint works when the UI sends `{memberKey, properties}` but fails gracefully for partial updates in some edge cases
- Helmet is not installed, WAL mode is not set, upload validation is missing, and security warnings are absent

### Implementation Steps (prioritized by impact)

#### 1. Enable SQLite WAL mode
**File:** `src/server/db/database.ts`  
Add `db.exec("PRAGMA journal_mode=WAL")` after database creation. Single line, prevents write-lock contention.

#### 2. Add security headers (Helmet)
**Files:** `package.json`, `src/server/app.ts`  
Install `helmet` package and add `app.use(helmet())` before routes. Adds X-Frame-Options, CSP, HSTS, etc.

#### 3. Add file upload validation (multer fileFilter + limits)
**File:** `src/server/routes/import.ts`  
Add `fileFilter` to reject non-xlsx/xml/csv files and `limits: { fileSize: 50 * 1024 * 1024 }` (50MB max).

#### 4. Add JWT secret startup warning
**File:** `src/server/index.ts`  
Log a warning if `config.auth.jwt.secret === "change-me-in-production"` and auth is enabled.

#### 5. Mask admin password in startup log
**File:** `src/server/index.ts`  
Change line 33 from logging the actual email/password hint to just logging "Default admin created (use ADMIN_EMAIL/ADMIN_PASSWORD env vars)".

#### 6. Add health endpoint DB check
**File:** `src/server/app.ts`  
Change `/api/health` to verify DB connectivity with a simple `SELECT 1` query.

#### 7. Improve member PATCH robustness
**File:** `src/server/routes/projects.ts`  
- Add a direct member lookup by ID (add `getById` to members repo) instead of loading all project members
- Return the full updated member record after patching

#### 8. Add request correlation IDs
**File:** `src/server/middleware/requestLogger.ts`  
Generate a `nanoid` per request, attach to `req` and include in log output.

#### 9. Add CORS configuration guidance
**File:** `config/dimbuilder.yaml`  
Add commented `corsOrigins` examples in the config file.

#### 10. Create `.env.example`
New file listing all supported environment variables with documentation.
