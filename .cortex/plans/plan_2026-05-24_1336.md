## Phase 1 Frontend Implementation Plan

### Context
The app uses a workspace-based navigation pattern in `AppShell.tsx`. The secondary nav has tabs (Project Overview, Validation, Admin, Config). New features will be added as additional secondary nav tabs. Components use `useState`/`useEffect`, call `apiGet`/`apiPost` from `src/client/api/client.ts`, and use shared UI primitives from `ui.tsx`. No chart library — we'll use CSS-based progress bars for scores.

### Implementation Steps

**Step 1: Add API client functions for new features**
- File: `src/client/api/client.ts`
- Add: `fetchHealthReport`, `fetchQualityScores`, `fetchAISuggestions`, `fetchDuplicates`, `fetchNamingAnomalies`, `fetchAuditLog`, `exportReport`

**Step 2: Create ReportingDashboard component**
- New file: `src/client/components/ReportingDashboard.tsx`
- Shows: Overall health score (large number + colored ring), per-dimension quality/completeness/naming scores as progress bars, export buttons (HTML/CSV/JSON), trend indicator
- Calls: `POST /api/reports/generate/health`, `POST /api/reports/export/:type`

**Step 3: Create AIInsightsPanel component**
- New file: `src/client/components/AIInsightsPanel.tsx`
- Shows: Duplicate detection results (grouped cards), naming anomalies (table with fix suggestions), parent suggestions, hierarchy optimizations
- Calls: `POST /api/ai/analysis`, `POST /api/ai/duplicates`, `POST /api/ai/naming-anomalies`

**Step 4: Create QualityScoresPanel component**
- New file: `src/client/components/QualityScoresPanel.tsx`
- Shows: Overall score gauge, per-dimension breakdown with color-coded bars, quality gates status (pass/fail), quality rules list
- Calls: `GET /api/projects/:id/quality/scores`, `GET /api/projects/:id/quality/gates`

**Step 5: Create AuditLogViewer component**
- New file: `src/client/components/AuditLogViewer.tsx`
- Shows: Sortable table of audit entries (who, what, when, entity), filterable by action/user
- Calls: `GET /api/projects/:id/audit-log`

**Step 6: Enhance WorkflowPanel with auto-advance status**
- File: `src/client/components/WorkflowPanel.tsx`
- Add: Auto-advance rule evaluation display, "Run Auto-Advance" button for admins, condition status chips (passed/failed)

**Step 7: Register new tabs in AppShell**
- File: `src/client/components/AppShell.tsx`
- Add 4 new secondary-nav tabs: "Reports", "AI Insights", "Quality", "Audit Log"
- Add workspace constants and conditional rendering in `<main>`

**Step 8: Add CSS styles for new components**
- File: `src/client/styles.css`
- Add: Score gauges (CSS-only circular progress), progress bars, audit log table, AI suggestion cards, export button group
