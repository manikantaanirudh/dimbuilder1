## Context

- **Repository pattern**: `createRepositories(db)` returns an object with `users`, `sessions`, `projectPermissions` namespaces with synchronous methods (better-sqlite3 is sync)
- **Route pattern**: Factory functions like `createProjectRouter(repos, config)` return Express `Router` instances
- **Middleware**: `authenticate.ts` parses Bearer tokens and sets `req.user`; `authorize.ts` provides `requireRole()` and `requirePermission()`
- **Validation**: `validateBody(zodSchema)` middleware for request body validation
- **Auth utilities**: `hashPassword`/`verifyPassword` (bcrypt, async), `signAccessToken`/`signRefreshToken`/`verifyRefreshToken` (jwt, sync)

- **IDs**: `nanoid()` throughout

## Implementation Steps

### Step 1: Create `src/server/routes/auth.ts`

Factory: `createAuthRouter(repos: Repositories, config: AppConfig): Router`

Endpoints:
- **POST /login** — Zod validate `{email, password}`, rate-limit (in-memory Map tracking failed attempts per email, 5 max in 60s), find user by email, verify password, sign tokens, hash refresh token with bcrypt before storing in session, update `lastLoginAt`, return `LoginResponse`
- **POST /refresh** — Validate `{refreshToken}`, verify JWT, find session by userId, compare bcrypt hash, check `expires_at`, sign new access token
- **POST /logout** — Optional Bearer parse (don't fail if missing), delete sessions for user, return 204
- **GET /me** — Require authentication (use `createAuthenticateMiddleware` or inline check), return `req.user`
- **POST /register** — Check if users table empty (use `listUsers().length === 0`), if first user allow without auth + force admin role; otherwise check `allowSelfRegistration`, validate body `{email, password, displayName}`, hash password, create user with `defaultRole`

### Step 2: Create `src/server/routes/users.ts`

Factory: `createUserRouter(repos: Repositories): Router`

All endpoints assume admin role (mounted with `requireRole("admin")` in app.ts):
- **GET /** — `listUsers()`, strip `password_hash` from each row
- **POST /** — Validate `{email, displayName, password?, role}`, hash password if provided, create user
- **PATCH /:id** — Validate `{displayName?, role?, isActive?}`, block self-deactivation and self-role-removal, update user
- **DELETE /:id** — Block self-deactivation, set `is_active = 0`, delete sessions, return 204

### Step 3: Create `src/test/auth.test.ts`

Integration tests:
- Set up server with auth enabled (`strategy: "local"`, `enabled: true`)
- Register first admin (no auth needed)
- Login → 200 with tokens + user
- Login with wrong password → 401
- GET /me with valid token → 200
- GET /me without token → 401
- POST /refresh with valid refresh token → new access token
- POST /logout → 204 + sessions cleared
- Rate limiting: 6 failed logins → 429

### Step 4: Wire routes in `src/server/app.ts`

Mount the new routers:
```
app.use("/api/auth", createAuthRouter(repos, config));
app.use("/api/users", createAuthenticateMiddleware(config), requireRole("admin"), createUserRouter(repos));
```

Auth routes are **before** the basicAuth middleware (they handle their own auth).
