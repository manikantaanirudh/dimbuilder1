## Context

The current layout uses a CSS Grid:
- **Row 1**: Top toolbar (navy header with logo, project name, action buttons) - spans all columns
- **Row 2**: Left sidebar (dimensions + Validation/Admin/Config nav) | Main content area

The user wants Validation, Admin, and Config moved from the sidebar to a **secondary horizontal bar** below the toolbar. The sidebar should only contain dimensions.

Additionally, update theme to match the actual SR website more closely:
- Darker navy: `#00204A` (from SR site CSS)
- Font: **Montserrat** (from SR site WebFont.load)
- The actual SR wordmark logo SVG (from their `<a class="brand">` element)
- SR favicon PNG from their CDN

## Implementation Steps

### Step 1: Add Secondary Navigation Bar (AppShell.tsx)

Move the Validation/Admin/Config buttons from the sidebar into a new `<nav className="secondary-nav">` element, placed between `</header>` and `<aside>`.

```tsx
{/* Between </header> and <aside> */}
<nav className="secondary-nav">
  <button
    className={`secondary-nav-item ${activeWorkspace === PROJECT_OVERVIEW_VALUE ? "active" : ""}`}
    onClick={() => setActiveWorkspace(PROJECT_OVERVIEW_VALUE)}
  >
    Project Overview
  </button>
  <button
    className={`secondary-nav-item ${activeWorkspace === VALIDATION_DASHBOARD_VALUE ? "active" : ""}`}
    onClick={() => setActiveWorkspace(VALIDATION_DASHBOARD_VALUE)}
  >
    Validation
  </button>
  <button
    className={`secondary-nav-item ${activeWorkspace === ADMIN_VALUE ? "active" : ""}`}
    onClick={() => setActiveWorkspace(ADMIN_VALUE)}
  >
    Admin
  </button>
  <button
    className={`secondary-nav-item ${activeWorkspace === CONFIG_EDITOR_VALUE ? "active" : ""}`}
    onClick={() => setActiveWorkspace(CONFIG_EDITOR_VALUE)}

</nav>
```

Remove the 3 buttons (Validation, Admin, Config) from the `<aside>` sidebar. Keep only the dimensions list in the sidebar.
