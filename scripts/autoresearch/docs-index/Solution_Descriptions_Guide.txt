Overview
The Solutions  identified  in this OneStream  Solutions  Description  are each  separate  and individual  
SKU’s,  but may be packaged  in a bundle,  as further  outlined  in your Order  Schedule.  Solutions  
may be categorized  as either  “Standard”  or “Reporting”  as further  specified  below.
Standard
Standard  Solutions  have  full access  and use rights  to all functionality,  including  read and write  
access,  in the specific  Solution.
Standard  Solutions  permit  an Authorized  Person  to change  data in a cube,  relational  table,  or 
other  modeling  apparatus  including:
 lAccessing  functionality  under  the “Application”  or “System”  tabs in the OneStream  
Windows  Desktop  application  or the equivalent  functionality  in other  user interfaces
 lModifying  values  stored  in a cube  or relational  table
 lExecuting  actions  that run calculations,  such  as Calculate,  Translate,  or Consolidate
 lImporting  data through  the Stage  engine  or other  data ingestion  mechanisms
 lModifying  predefined  reports  or dashboards
 lExecuting  data management  jobs or tasks  that modify  stored  data

Service  Limits  – SensibleAI  Forecast
 OneStream  SensibleAI  Forecast  is a separately  priced  product,  and additional  fees will apply  
based  on the number  of Targets  defined  in the customer  Order  Schedule.  
“Target”  means  a data element  in the SensibleAI  Solution  in which:  i) Customer  historical  data is 
ingested;  and ii) forecast  data is generated  by the SensibleAI  Solution.  Targets  are consumed  
across  both production  and non-production  environments.  
Please  see below  for Service  Limits  applicable  to SensibleAI  Studio  Essentials  Package.

SensibleAI  Studio  - Standard  consists  of full access  and use rights  to the following  application  
from the OneStream  Solution  Exchange:
 l SensibleAI  Essentials  Package  
 lSensibleAI  Studio  Standard  Routines  
 lSensibleAI  Studio  Standard  Solutions

Service  Limits  – SensibleAI  Essentials  Package  and SensibleAI  Studio  - Standard
 1. A maximum  of 3000  Invocations  per calendar  quarter  of LLM Chat  Models  surface  through  
SensibleAI  Studio  and Xperiflow  Business  Rules.  
 2.  A maximum  of 300,000  LLM Embedding  Generations  per calendar  quarter.  
 3.  A maximum  of 100,000  Code  Scan  Units  per calendar  quarter.  
 Any unused  Invocations,  LLM Embedding  Generations  or Code  Scan  Units  may not be rolled  
over and consumed  during  a subsequent  calendar  quarter.  
“Invocation”  means  a single  call or execution  of a service,  function,  or model  within  the Platform.   
“LLM  Embedding  Generation”  means  single  operation  where  an LLM embedding  model  
processes  one discrete  sub-set of text to produce  its numeric  embedding  representation.
 “Code  Scan  Unit”  means  single  evaluation  that checks  a specific  code  file ("Scan  Item")  against  
one Condition,  returning  any matching  instances  within  that file.
 “Condition”  means  predefined  coding  pattern  or issue  (e.g.,  "Unnecessary  Logging  Statements",  
"Nested  SQL loops")  that the scanning  process  searches  for within  a Scan  Item.
