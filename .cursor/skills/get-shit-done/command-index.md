# GSD command index (dimbuilder)

Skills install globally at `~/.cursor/skills/<name>/SKILL.md`. Invoke by name in Agent chat.

## Core loop

| Skill | Use when |
|-------|----------|
| `gsd-map-codebase` | **First** — brownfield analysis of dimbuilder |
| `gsd-new-project` | Roadmap + requirements (after map) |
| `gsd-discuss-phase` | Gray areas before planning phase N |
| `gsd-plan-phase` | Research + executable plans |
| `gsd-execute-phase` | Run plans in parallel waves |
| `gsd-verify-work` | Acceptance testing |
| `gsd-ship` | PR from verified phase |
| `gsd-complete-milestone` | Archive + tag |
| `gsd-new-milestone` | Next version cycle |
| `gsd-progress` | Auto-detect next step |

## Namespace routers

| Skill | Routes to |
|-------|-----------|
| `gsd-workflow` | discuss / plan / execute / verify |
| `gsd-project` | milestones, audits |
| `gsd-quality` | review, debug, security |
| `gsd-context` | map, docs |
| `gsd-manage` | config, update, ship |
| `gsd-ideate` | explore, spike, spec |

## dimbuilder-related extras

| Skill | Use when |
|-------|----------|
| `gsd-settings` | Tune `.planning/config.json` |
| `gsd-code-review` | Phase or PR review |
| `gsd-debug` | Structured debugging |
