# Superpowers skill index

Load via plugin skills list or:

`https://raw.githubusercontent.com/obra/superpowers/main/skills/<name>/SKILL.md`

## Process (use first)

| Skill | Use when |
|-------|----------|
| `using-superpowers` | Session start; how to find and prioritize skills |
| `brainstorming` | Any creative work: features, components, behavior changes — **before code** |
| `writing-plans` | Spec approved; need implementation plan with TDD steps |
| `using-git-worktrees` | After design approval; isolated branch + clean test baseline |
| `subagent-driven-development` | Executing plan; one subagent per task + two-stage review |
| `executing-plans` | Same plan, inline batches with human checkpoints |
| `dispatching-parallel-agents` | Independent tasks that can run concurrently |
| `finishing-a-development-branch` | Plan complete; merge / PR / keep / discard |

## Quality

| Skill | Use when |
|-------|----------|
| `test-driven-development` | Writing or changing production code |
| `systematic-debugging` | Bugs, failures, unexpected behavior |
| `verification-before-completion` | About to say "fixed" or "done" |
| `requesting-code-review` | Between tasks or before merge |
| `receiving-code-review` | Addressing review feedback |
