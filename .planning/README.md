# GSD planning artifacts

Created and maintained by [GSD Core](https://github.com/open-gsd/gsd-core) when you run `gsd-new-project`, `gsd-plan-phase`, and related commands.

See [docs/gsd/README.md](../docs/gsd/README.md) for how to start on dimbuilder.

Typical files after initialization:

- `PROJECT.md` — vision and context
- `REQUIREMENTS.md` — scoped requirements
- `ROADMAP.md` — phases and status
- `STATE.md` — session memory
- `config.json` — workflow settings
- `phases/` — per-phase plans and research
